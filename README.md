
# CatchUp

*A playful Unity mini-game about guiding a ketchup missile to the finish line.*

## Overview

CatchUp is an early game development project created with Unity. The concept is simple: guide a ketchup missile toward the finish line, combining a playful idea with hands-on experimentation in game physics and visual effects.

The project provided an opportunity to explore Unity's lighting, physics, and particle systems while learning the fundamentals of interactive game development.

## Gameplay

The objective is to guide the ketchup missile to the finish line.

The project explores how physics and player interaction can be combined to create a simple, engaging gameplay experience.

## Key Highlights

- **Physics:** Experimentation with Unity's physics system to support gameplay interactions.
- **Lighting:** Exploration of lighting effects to enhance the game's visual presentation.
- **Particle Systems:** Experimentation with particle effects to add visual feedback.
- **Gameplay Design:** A simple, goal-oriented mechanic built around guiding a projectile to its destination.

## Technology Stack

- **Game Engine:** Unity
- **Physics:** Unity Physics
- **Visual Effects:** Unity Particle System
- **Lighting:** Unity lighting tools
